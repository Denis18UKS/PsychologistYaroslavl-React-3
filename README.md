# Psychologist Yaroslavl — Concept 3 FIXED

Премиальный одностраничный сайт психолога в Ярославле.

## Визуал и функции

- Светлая и тёмная тема через переключатель ☀ ↔ ☾.
- Плавные анимации карточек и секций.
- Reveal-анимации при прокрутке через IntersectionObserver.
- Адаптив для desktop / tablet / mobile.
- Интерактивный FAQ.
- Форма заявки с подготовленным сообщением для Telegram.
- Контакты, формат работы, стоимость, отзывы.
- SEO-мета-теги и sitemap.

## Важное исправление установщика

Предыдущий вариант мог открыть браузер раньше, чем локальный HTTP-сервер успевал начать слушать порт. В FIXED-версии сервер сначала получает реальный listener, затем запускается HTTP-обслуживание, после чего установщик ждёт успешный HTTP-запрос и только затем открывает браузер.

Дополнительно production-страница содержит полноценный fallback-разметку: если браузер не загрузит React runtime или React завершится с ошибкой, пользователь всё равно увидит сайт, включая локальное переключение темы и FAQ.

## Локальная production-сборка

`dist/` — готовая автономная версия.

React и ReactDOM лежат локально в `dist/assets/`, поэтому сайт не зависит от CDN.

## Запуск установщика

`installer/main.go` собирается под Windows x64.

Установщик разворачивает сайт в:

`%LOCALAPPDATA%\\PsychologistYaroslavlConcept3Fixed`

и запускает localhost-сервер на первом свободном порту начиная с `5273`.
