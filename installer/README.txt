Psychologist Yaroslavl — Concept 3

Запуск готового сайта:
1. Двойной клик по PsychologistYaroslavl-Concept-3-Setup.exe.
2. Установщик развернёт сайт в %LOCALAPPDATA%\PsychologistYaroslavlConcept3.
3. Сайт запустится на локальном адресе 127.0.0.1 и автоматически откроется в браузере.

Для остановки локального сайта завершите процесс установщика в Диспетчере задач.

Внешние подключения не нужны: React runtime, JavaScript и CSS входят внутрь EXE.
